# Goiter — Complete Medical Presentation

عرض HTML مكوّن من 41 شريحة (حسب `manifest.json`)، مُجمَّع ومشغَّل كما هو دون أي تعديل على ملفات الشرائح أو التصميم أو الأنيميشن.

## التشغيل

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## التنقّل

- الأسهم / مسافة / PageUp / PageDown: شريحة تالية وسابقة
- النقر على طرفي الشريحة، أو أزرار Prev / Next، أو السحب على الشاشات اللمسية
- `Home` / `End`: أول / آخر شريحة — `F`: ملء الشاشة — `Esc`: إغلاق نظرة الشرائح
- زر **Replay** يعيد تشغيل أنيميشن الشريحة الحالية من البداية
- زر **Slides** يعرض كل الشرائح للانتقال المباشر لأي شريحة، ورابط مثل `index.html#12` يفتح الشريحة 12 مباشرة

## ملاحظات

- لم يُعدَّل أي ملف شريحة (`*.html`) ولا `theme.css` الأصلي إطلاقًا (`git diff` فارغ).
- أُضيف فقط: `index.html` (المشغّل) ومجلد `assets/` (نسخ من `theme.css` والصور) لأن الشرائح تشير أصلًا إلى `../assets/...`، فاكتملت بذلك المسارات كما صُممت.
- الأنيميشن (`fx`/`ff` و`d1`–`d8` في `theme.css`) يعمل كما هو، ويُعاد تشغيله تلقائيًا عند كل انتقال بين الشرائح.
